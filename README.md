# Analor (cópia de teste da Camila)

Cópia de teste do Analor com os módulos novos (Identificação completa com busca integrada, Analin, Anamass, Anamag, Analab e Anaquim). É só o app já compilado, para abrir e instalar no celular ou no computador.

Endereço: https://calisants.github.io/analor-teste/

O código-fonte fica no repositório do Analor, na branch `camila-anaquim`. O arquivo `dados/identificar.json` é a base de compostos usada pela Identificação completa.
